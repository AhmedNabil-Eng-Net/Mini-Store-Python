# 🛍️ Mini Store

A simple command-line shopping cart application built with Python.

## ✨ Features

* 🛒 Browse available products and prices
* ➕ Add items to the shopping cart
* 🧾 View the current cart
* 💰 Track the total cost
* ⚠️ Handle invalid items and inputs
* 🔄 Continue shopping or exit anytime

## 🛠️ Technologies

* Python
* Dictionaries
* Lists
* Loops
* Conditional Statements
* String Methods
* Input Validation

## 🚀 How to Run

Make sure Python is installed on your computer.

Run the application with:

```bash
main.py
```

## 🎮 How to Use

When the application starts, the available menu is displayed.

Enter the name of the item you want to add:

```text
🛍 - Menu -
soda : 3.25$
fries: 6.35$
chips: 1.79$
pepsi: 2.81$
pizza: 4.56$

- 🛒 Select an item (or q to quit): pizza
```

The selected item is added to the cart and the total price is updated:

```text
✅ pizza: 4.56$ has been added to your cart.
🧾 Cart: [pizza]
💰 Total cost: 4.56$
```

Type:

```text
q
```

to exit the application.
